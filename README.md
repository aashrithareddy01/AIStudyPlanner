# AI Study Planner

An AI-based study planner that generates a personalized timetable for students based on subjects, exam dates, and weak topics.

# Features

* Personalized study timetable
* Weak subject prioritization
* Responsive UI
* Easy to use

# Technologies Used

* HTML
* CSS
* JavaScript

# How to Run

1. Download the project
2. Open `index.html`
3. Start planning your studies
